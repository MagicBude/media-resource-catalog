# Competitive Findings

此文档记录前期竞品研究形成的产品结论，不作为实时网站状态数据库。

## 影巢 / HDHive

值得借鉴：

- Media 与 Resource 绑定
- 结构化影视资料
- 资源分享层
- API / Provider 思维

我们的改进：

- 进一步将 Release 与 Share 分离
- 强化 Provenance

## 癫影

值得借鉴：

- 极简“搜索 → 作品 → 资源”路径
- 不让首页被复杂功能淹没

## FRAMEHDR / 帧影

值得借鉴：

- 海报墙
- 分类浏览
- 年份浏览
- 最近更新
- 更新日历思维
- 资源覆盖信息适合直接进入卡片

## 聚影

最值得借鉴的是社区治理：

- 先确认作品身份再投稿
- 奖励有效贡献而非上传数量
- 重复 / 失效资源不应获得同等奖励
- 核验、举报、纠错、信誉体系

## RDhub

主要借鉴搜索导向的交互，而不是作为数据模型模板。

## PanSou

定位为 **Search Provider / Discovery Provider**，而不是网站本体。

我们的系统不应复制 PanSou 全网搜索能力，而是消费它返回的 Candidate。

## MediaSync115 / Mediary Scout

说明外部自动化工具确实需要：

- 结构化 Media
- 结构化 Release Quality
- Provider Search
- 可筛选资源
- 稳定 API

这验证了“网站作为结构化资源 Provider”这一长期方向。
