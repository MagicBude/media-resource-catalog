# Product Vision

## 一句话

**找到你真正想要的那个版本。**

## 定位

Media Resource Catalog 是以影视作品为核心的**结构化影视资源索引与整理平台**。

它回答四个问题：

1. 这是什么作品？
2. 这个作品有哪些具体资源版本？
3. 每个资源版本可以在哪里找到？
4. 这些信息从哪里来、是否可信？

## 不是什么

不是：

- 普通全网盘关键词搜索器
- 在线播放器
- 视频托管站
- 自动下载器
- 用户网盘 Cookie 托管平台

## 核心价值

传统盘搜结果以链接为中心，容易出现：

- 同作品大量重复
- 同 Release 多个链接被当成多个资源
- 资源质量无法结构化筛选
- 来源不可追踪
- 失效状态不可治理
- 第三方工具难以稳定消费

本项目通过：

```text
Media → Release → Share → Provenance
```

把这些概念拆开。
