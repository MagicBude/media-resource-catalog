## 分类说明

### product

产品定位、范围、竞品结论、长期决策。

### architecture

模块边界、依赖方向、数据流、运行时架构。

### data-model

正式领域实体、字段、关系、唯一约束与状态。

### providers

外部资源发现 Provider 的统一边界。

### search

Catalog Search 与 Resource Discovery 两套搜索体系。

### ui

网站信息架构、路由与页面规格。

### community

用户、投稿、核验、积分、举报、审计。

### api

对第三方工具开放的稳定 API 方向。

### security

凭据、内容边界、审计、下架等安全与合规基线。

### development

本地开发、命令、测试、编码规范。

### roadmap

版本阶段与里程碑。

### handoff

当前状态、下一步以及已作出的关键决策。
