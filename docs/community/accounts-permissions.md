# Accounts & Permissions

## Role

```text
user
trusted
moderator
admin
```

## Guest

- 浏览
- 搜索
- 查看 Media
- 查看 Release

真实 Share URL 是否游客可见，保留为策略配置，不在 V0.1 写死。

## User

增加：

- 收藏
- 投稿
- 验证
- 举报
- 查看贡献

## Trusted

增加：

- 更高投稿额度
- 更高验证权重
- 部分自动审核资格

## Moderator

增加：

- 处理举报
- 合并 Release
- 修正 Media Match
- 处理 Duplicate
- 隐藏 Share

## Admin

增加：

- Provider 管理
- 用户管理
- 系统设置
- 审核策略
- Jobs
- Audit
